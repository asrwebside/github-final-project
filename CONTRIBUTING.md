# Contributing Guidelines

Contributions to the Simple Interest Calculator project are welcome!

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Create a branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear commit message.
5. Push your branch to your fork.
6. Open a pull request describing your contribution.

## Reporting Bugs

When reporting a bug, describe the problem, the steps to reproduce it, and the expected behavior.

## Code Guidelines

- Keep Bash scripts readable and simple.
- Use meaningful variable names.
- Test changes before submitting them.
- Update documentation when necessary.

Thank you for helping improve this project!
