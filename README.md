# github-final-project

## Simple Interest Calculator

The Simple Interest Calculator is an open-source Bash project that calculates simple interest based on the principal amount, annual interest rate, and time period in years.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

- **Principal (P):** The initial amount of money.
- **Rate (R):** The annual interest rate expressed as a percentage.
- **Time (T):** The time period in years.

## Requirements

- A Bash-compatible terminal.
- `awk` for the interest calculation.

## How to Run

Execute the script from your terminal:

```bash
bash simple-interest.sh
```

Enter the principal amount, annual rate of interest, and time period when prompted.

## Example

Input:

- Principal: 1000
- Rate: 5%
- Time: 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100 = 100

Output:

```text
Simple Interest: 100.00
```
